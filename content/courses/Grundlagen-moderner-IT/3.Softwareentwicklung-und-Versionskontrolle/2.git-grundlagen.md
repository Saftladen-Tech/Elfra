## Grundbefehle

```bash
git clone <repo>
git add .
git commit -m "Beschreibung"
git push
```

## Branching‑Modell

- main/master – stabile Version
- feature branches – neue Funktionen
- hotfix branches – schnelle Fehlerbehebung
